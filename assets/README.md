# Assets to add before you start (5 minutes)

Claude Code can build everything without these, but the prototype looks right only with your real brand files.

## 1. Logo (strongly recommended)
Copy your official logo files here, then Claude Code will move them to `public/brand/`:
- `assets/brand/logo.svg` - full logo (mark + "Rizzfitt" wordmark), for dark backgrounds (white or light wordmark).
- `assets/brand/logo-mark.svg` - the orange mark alone (favicon, app icon, loaders).
- Optional: `assets/brand/logo-dark-on-light.svg`.

You can download the current ones from the live product (for example `https://manage.rizzfitt.com/logo.svg` and `https://manage.rizzfitt.com/common/rizz.svg`) if you do not have the design files. Without them, the prototype shows a text wordmark placeholder and never imitates the mark.

## 2. Gilroy font (recommended)
Gilroy is a licensed typeface that the product already uses. If your licence allows it, copy the files here:
- `assets/fonts/Gilroy-Regular` (.woff2 preferred, .ttf accepted)
- `assets/fonts/Gilroy-Medium`
- `assets/fonts/Gilroy-SemiBold`
- `assets/fonts/Gilroy-Bold`

Without them, the prototype uses Outfit (open licence, similar geometric style).

## 3. Optional
- Real sponsor logos you have permission to show (otherwise the prototype uses invented text logos).
- A few event photos you have rights to (otherwise the prototype uses 3D renders and gradients).

Do not add player data, phone numbers or emails. The prototype only uses invented people.
